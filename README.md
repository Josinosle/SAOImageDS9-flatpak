# SAOImage DS9
## Unofficial flatpak distribution  
This is a simple github workflow to automatically push DS9 source to a flatpak. I built this to have a signed flatpak package for working on my masters thesis at the time and viewing FITS files on an immutable linux distro. For the actual repository and a more official flatpak build see the links below as these are more encouraged, they were used partially in the build of this flatpak. 
  
Site: https://sites.google.com/cfa.harvard.edu/saoimageds9  
Original Github: https://github.com/SAOImageDS9/SAOImageDS9  
  
Github repo providing similar thing from official source: https://github.com/SAOImageDS9/build_flatpak
